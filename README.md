# 12시대

성경 66권을 **열두 시대**로 나눠, 처음부터 끝까지 하나의 이야기로 따라가는 교재입니다.

- 성경을 한 번도 읽어 보지 않아도 읽을 수 있게 썼습니다.
- 해석이 갈리는 곳은 "이게 정답입니다" 대신 **여러 견해가 있다**고 적었습니다.
- 성경이 직접 이어 준 것과 후대에 닮은꼴로 읽는 것을 **구분**해서 표시했습니다.

현재 **여는 장 ~ 3장**이 공개되어 있고, 나머지는 제작 중입니다.
